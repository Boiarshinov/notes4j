# ASN.1

__ASN.1__ - Abstract Syntax Notation One - это нотация описания структур данных.
Нотация не привязана к какой-либо технологии, что позволяет обмениваться сообщениями, сформированными по правилам ASN.1 с помощью любых языков программирования.

ASN.1 описывается стандартом X.680, а способ его сериализации - стандартом X.690.

ASN.1 стал де-факто стандартом в области телекоммуникаций и криптографии.
С его помощью описываются структуры данных [сертификатов](../security/digital_certificate.md), криптографических сообщений - CMS, time stamp protocol (TSP), протокол [kerberos](../security/kerberos.md) и многое другое.

В отличие от других бинарных форматов (вроде [protobuf](./protobuf.md), thrift и других) ASN.1 не предоставляет готовых инструментов для компиляции описанных структур в популярные языки программирования и для сериализации данных.
Для криптографических целей самой популярной библиотекой, по крайней мере в JVM-мире, стала bouncy castle.
Для компиляции собственных структур в различные языки программирования существуют коммерческие инструменты, такие как OSS.


## Сериализация

Стандарт ASN.1 не описывает конкретный способ сериализации, но в индустрии появилось несколько стандартных подходов.
Самыми популярными являются форматы __BER__, __CER__ и __DER__.
Они описаны в стандарте X.690.
- _BER_ - Basic Encoding Rules
- _CER_ - Canonical Encoding Rules
- _DER_ - Distinguished Encoding Rules 

DER и CER являются подмножеством BER и отличаются от него тем, что позволяют сериализовать объект только одним способом.
В BER же поле типа Boolean со значением true можно задать любым ненулевым байтом, что может приводить к различным трактовкам.
Поэтому в криптографии как правило используется DER или CER.
