# Web Application Firewall

Web Application Firewall (__WAF__) - это средство защиты web-приложений, анализирующее входящий (и исходящий) трафик и фильтрующее трафик от злоумышленников.
WAF работают на прикладном уровне [модели OSI](../network/osi.md).

WAF старается защищать от всех возможных векторов атаки, в особенности от самых популярных, которые перечислены в OWASP.
WAF не ультимативное средство защиты, оно не может распознать злоумышленников, действующих на бизнес-уровне, поэтому защита приложений не должна ограничиваться только WAF. 

Как правило, весь входящий трафик проходит через WAF, а потому WAF должен обеспечивать высокую скорость обработки.
Например, среднее время обработки HTTP-запроса на стороне PTAF составляет ~100 мкс.

WAF могут поставляться в разных видах:
- в виде приложения, разворачиваемого на серверах заказчика
- в виде hardware коробки (видимо ТСПУ можно отнести к WAF такого вида)
- в виде облачного сервиса

Популярные решения:
- Cloudflare - облачное решение.
- PTAF - WAF от Positive technologies. Разворачивается on-premise, также есть cloud.
