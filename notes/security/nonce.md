# Nonce

__Nonce__ - Number used once - число, которое может быть использовано только один раз.
Nonce используется в криптографии для защиты от __reply атак__.
В качестве nonce необязательно использовать число, это может быть и строка или просто массив бит.
Nonce может быть как случайным, так и последовательным, главное чтобы он был уникальным.
Также nonce можно генерировать на основе системного времени (например, использовать [UUID v7](../common/uuid.md))

__Reply-атака__ - это такой вид атаки, когда злоумышленник перехватывает запрос от клиента к серверу, а затем перепосылает его в неизменном виде.
Без должной защиты на стороне сервера это может приводить к повторным обработкам запросов.
Особенно опасно это при аутентификации пользователя и выдаче ему сессионного ключа.
С помощью reply-атаки злоумышленник может завладеть сессией пользователя и совершать операции под именем пользователя.
Для дедубликации запросов на стороне сервера в запрос от клиента добавляют __nonce__.

Nonce может генерироваться как на стороне клиента, так и на стороне сервера.

![nonce sequence diagram](../../images/src/nonce.uml)

Nonce как правило хранится на стороне сервера в течение некоторого временного окна.
Для того, чтобы исключить возможность reply атаки за пределами этого временного окна, в запрос также добавляют timestamp (либо включают его в сам nonce).
Если этот timestamp отличается от времени на сервере на ширину временного окна, то запрос признается невалидным.

---
## Другие применения

Nonce используется в __proof-of-work__ системах. 
Nonce добавляется к данным, после чего вычисляется хэш.
Перебираются различные значения nonce так, чтобы хэш в итоге имел некоторое количество нулей на конце.
Затем хэш, nonce и данные направляются на сервер, который может легко проверить результат.
