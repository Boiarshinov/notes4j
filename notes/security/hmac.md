# HMAC

__HMAC__ - Hash-based Message Authentication Code.
HMAC - это MAC, использующий [криптографическую хэш-функцию](./crypto_hash_function.md).
HMAC используется для проверки целостности сообщений при их пересылке по незащищенному каналу.

Для применения HMAC две стороны Alice и Bob должны сначала обменяться секретным ключом.
При отправке сообщения Alice вычисляет HMAC на основе ключа и отправляемых данных.
Alice добавляет вычисленное значение HMAC и отправляет его Bob.
Bob на своей стороне вычисляет HMAC на основе полученных данных и сравнивает его со значением, переданным Alice.
Если значения совпали, то значит, что данные дошли без изменений.

Также HMAC может использоваться для проверки целостности данных при их хранении, чтобы защититься от внесения изменений например, администратором системы.

HMAC позволяет использовать для формирования MAC любые криптографические хэш-функции, даже те, которые не умеют работать с секретными ключами.

### Алгоритм работы
```
H(K XOR opad + H(K XOR ipad + text))
```
, где `H` - криптографическая хэш-функция, `K` - секретный ключ, `text` - данные, подлежащие проверке целостности, `opad` и `ipad` - стандартные битовые маски, а `+` - это конкатенация.

Хэши, рассчитанные с помощью HMAC иногда обрезают слева до заданной длины.
Это скрывает часть хэша от злоумышленников, что усложняет задачу по реверс-инжинирингу.

### Наименование
Название HMAC отражает его параметры:
```
HMAC-<hash-function>[-<length>]
```
, здесь `hash-function` - это краткое название хэш-функции, а `length` - это длина в байтах после обрезки.
Если длина в названии не указывается, то это значит, что обрезка не проводится, а используется полное значение вычисленного хэша.

Примеры наименований:
- `HMAC-MD5`
- `HMAC-SHA512/256`
- `HMAC-SHA1-80`
