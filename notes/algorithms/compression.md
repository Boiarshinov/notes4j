# Сжатие данных

Сжатие - это процесс уменьшения занимаемого объема данных без уменьшения количества информации.
Сжатие данных полезно как при хранении данных, так и при их передаче по сети.

Существует два основных класса алгоритмов сжатия:
- сжатие без потерь (_lossless_) - сжатые данные могут быть восстановлены до бита.
- сжатие с потерями (_lossy_) - сжатые данные восстанавливаются с допустимыми потерями.

Как правило, для каждого типа данных подходит разный класс сжатия и алгоритм сжатия.
Для музыки, видео, изображений можно использовать сжатие с потерями, отрезая например частоты, которые не может воспринять человеческий слух, или объединяя цвета, которые идентичны для человеческого глаза.
Для текста или структурированных данных сжатие с потерями неприменимо.

Разные алгоритмы сжатия используются для разных типов данных.
Для музыки это MP3, для видео - MPEG-4, для изображений - JPEG и PNG, и т.д.

В ряде случаев сжатие недопустимо.
Например, в [TLS](../network/tls.md), начиная с версии 1.3 отключена возможность сжатия на транспортном уровне, т.к. это давало возможность злоумышленникам частично восстановить зашифрованные данные.

## Популярные алгоритмы

Алгоритмы сжатия без потерь:
- __Deflate__ - используется в gzip, в png.
- __LZMA__ - сжимает лучше, чем Deflate, но расходует больше ресурсов. Используется в утилите 7z, в Debian для сжатия пакетов.
- __Brotli__ - алгоритм сжатия, разработанный в google и предназначенный для web. Поставляется с словарем часто встречающихся значений в html и других web-документов. Зафиксирован в стандарте RFC-7932.
- __LZ77__ - основополагающий алгоритм сжатия, разработанный в 1977 году. Использует скользящие окна. Стал базой для многих последующих алгоритмов сжатия. Сам по себе уже не используется.
- __LZ4__ - основан на LZ77. Обладает скоростью распаковки в несколько раз выше, чем у Deflate. Используется в Hadoop.
- __Zstandard__ - разработан в Facebook на основе LZ77. Обладает высокой степенью сжатия, сопоставимой с deflate, и одной из самых высоких скоростей среди конкурентов. Используется в файловой системе Fedora. Используется в образах игр для Nintendo Switch.
