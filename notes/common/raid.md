# RAID

__RAID__ - Redundant Array of Independent Disks - технология объединения нескольких физических дисков в один виртуальный с избыточностью хранения.
RAID позволяет не потерять данные при выходе из строя одного из физических дисков за счет избыточности хранения.

Существуют различные способы конфигурации RAID (рассмотрены не все):
- __RAID 0__ - Избыточности хранения вообще нет. 
  Каждый элемент хранения присутствует только на одном диске. 
  Преимущество - быстрое чтение, например, при чтении сразу нескольких файлов IO-поток может быть быстрее чтения с одного диска пропорционально количеству дисков.
- __RAID 1__ - Каждый элемент хранения дублируется на еще одном физическом диске.
  Полезный объем дисков уменьшается вдвое, но при выходе из строя одного диска данные не будут потеряны.
- __RAID 10__ - Массив RAID 0, построенный из RAID 1. 
  Например, диски объединяются попарно в RAID 1, а из этих пар составляется RAID 0.
- __RAID 5__ - Элемент хранения разбивается на блоки, которые хранятся на разных дисках, при этом на одном из дисков будет храниться избыточный блок данных, позволяющий восстановить любой блок данных этого элемента хранения.
  Минимальное количество дисков - 3.
  Преимущество - экономичность: общий объем данных в массиве, если каждый диск имеет размер S: `(n-1)*S`.
  Недостатки - Массив RAID 5 плохо работает на произвольное чтение и при выходе одного диска из строя требует продолжительных работ по восстановлению данных.
